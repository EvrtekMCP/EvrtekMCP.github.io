# CREDITS

8-BIT GAMBIT is the one Arcade cabinet that **does** ship third-party code, and
it ships it whole rather than copied in pieces. Everything third-party lives in
`vendor/` with its original licence notice intact. All game code, art and sound
are original: the pieces and board are drawn in code, and every sound is
synthesized at runtime with the browser's built-in Web Audio API. The game makes
zero network requests — it runs from a double-clicked file.

## Third-party code (bundled, licences retained in the files)

- **chess.js v1.4.0** — © 2025 Jeff Hlywa, BSD 2-Clause licence. Move
  generation, legality, check/checkmate/stalemate detection, FEN and PGN. The
  full copyright notice and licence text are retained inside
  `vendor/chess.js` and `vendor/chess.esm.js` as that licence requires.
  `vendor/chess.js` is the upstream ESM build converted to a classic script so
  the game runs from `file://` without a server; the library's own code is
  unmodified.
- **Peggy 4.2.0** (MIT) — chess.js's PGN parser is generated by Peggy, so the
  generated parser travels inside the files above. Not a separate download.

## Fonts

- **Press Start 2P** — SIL Open Font Licence 1.1, embedded as a base64 data URI
  in `css/font.css` so the cabinet works offline and from `file://`. Nothing is
  fetched from a font host.

## Original work

Board, pieces, palette, UI, animation, sound design and the engine's opponent
logic are original to this project. No sprite sheets, tilesets, piece sets or
audio samples were downloaded, hotlinked, traced or sampled.
