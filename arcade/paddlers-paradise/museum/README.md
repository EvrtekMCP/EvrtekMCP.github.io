# PORTAGE — museum copies

Frozen, self-contained builds preserved exactly as they were when Evrtek
played them. One file each, runs from a double-click, no server, no assets.
Never edited after filing — history is append-only here, like the journals.

- **portage-v0.1.2.html** — the one-shot build (2026-08-27): the original
  three-day trip as first delivered, with the review fleet's fixes and the
  crisp-text/phone-zoom pass. Filed before the v0.2.0 major update began,
  at Evrtek's order: "store a copy of the game in its current state for
  the museum."

- **portage-v0.8.0.html** — the Arcade release (2026-08-30): three trips with
  fleet records, camp as its own hand-authored scene, fire-tending, fishing,
  sky events, vistas, ten species. Filed by the MCP on 2026-09-04 in the hour
  before v1.0.0 overwrote it, per the Arcade release standard (major updates
  preserve the prior version). Inlined from the files that were actually being
  served, so it is the build players had, not a rebuild.
