# CREDITS

Beat Machine ships **no third-party code and no audio assets**. Every sound is
synthesized at runtime with the browser's built-in Web Audio API. Nothing is
downloaded, hotlinked, or sampled.

Reference material consulted (techniques studied, no code or assets copied):

- **io-808** (https://github.com/vincentriemer/io-808, MIT) — reference for
  classic analog drum-voice synthesis recipes (oscillator/noise/envelope
  topologies).
- **web.dev "A tale of two clocks"** — the lookahead audio-scheduling pattern.
- **jsfxr** (public domain) — inspiration for the arcade blip voice character.

Trademark note: voice names use generic "808-style"/"classic analog"
descriptions. This project is not affiliated with, sponsored by, or endorsed by
Roland Corporation or any instrument manufacturer.
